# PROJETO: Laravel study project

A fresh Laravel 10 application (PHP 8.1) that I set up in 2023 while learning PHP and the MVC pattern. It contains the default project structure and is kept here as a record of that work.

## Running

```bash
cd example-app
composer install
cp .env.example .env
php artisan key:generate
php artisan serve
```
